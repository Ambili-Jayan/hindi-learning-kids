📱 हिंदी पाठशाला - Kids Hindi Learning Web App

A fun, interactive, and gamified web application designed to help kids learn Hindi letters, numbers, vocabulary, grammar basics, and short stories with audio pronunciations, speech recording practice, interactive letter tracing, and collectible sticker rewards!

Live Demo: hindi-learning-kids.netlify.app

✨ Features Overview

7 Structured Curriculum Levels: Step-by-step progressive learning tailored for beginners.

🔊 Voice Pronunciation & Hover Audio: Automatic Hindi text-to-speech engine (SpeechSynthesisUtterance). Kids can tap any card or hover over text to hear native Hindi pronunciations.

🎤 Interactive Speech Practice: Kids can record their own voice reading sentences and get instant feedback with accuracy word-matching.

🎯 10-Question Level Quizzes: Interactive audio and visual multiple-choice quizzes for every level with score tracking.

🏆 Collectible Sticker Rewards: Kids earn star points and unlock unique Hindi achievement stickers upon completing each level quiz!

✏️ Interactive Letter Tracing Pad: Built-in HTML5 Canvas for practicing Devanagari stroke order with customizable brush colors.

📱 Mobile & Tablet Optimized: Designed with touch-friendly cards, scalable fonts, and responsive grid layouts. Can be saved directly to iPad or Android home screens as an app!

📚 Curriculum Breakdown

Level

Title

Description

Level 1

Letters (अक्षर)

Full Devanagari Varnamala: Vowels (Swar) & Consonants (Vyanjan) with example words, emojis, and audio.

Level 2

Numbers 1-50 (गिनती)

Hindi digits (१ से ५०) with Devanagari word spellings and transliterations.

Level 3

Small Words (छोटे शब्द)

10 Animals, 10 Fruits & Veggies, 10 Everyday Things, Colors, and Shapes with visual cards.

Level 4

Sentences (छोटे वाक्य)

Daily conversation sentences with listen and mic recording features.

Level 5

Grammar (व्याकरण)

Simple rules and examples for Nouns (संज्ञा), Pronouns (सर्वनाम), and Opposites (विलोम शब्द).

Level 6

Synonyms (समान अर्थ)

Synonyms (पर्यायवाची शब्द) explained with dual audio and visual pairs.

Level 7

Stories (कहानियाँ)

Short moral stories broken into sentence-by-sentence reading cards.

Activity

Interactive drawing canvas for practicing character strokes.

Level-specific 10-question quizzes to test retention and award stickers.

🛠️ Tech Stack

HTML5 & CSS3 (Single-file web app architecture)

Tailwind CSS (via CDN for responsive, colorful UI)

Vanilla JavaScript (ES6+)

Web Speech API (SpeechSynthesisUtterance & webkitSpeechRecognition)

Web Audio API (Custom sound effect synthesizer for correct/wrong/star chime SFX)

HTML5 Canvas API (For interactive letter tracing)

Google Fonts (Baloo 2 for Devanagari & Fredoka for English text)

🚀 How to Run Locally

Clone or download this repository:

git clone https://github.com/your-username/hindi-learning-kids.git


Navigate into the folder:

cd hindi-learning-kids


Open index.html in any web browser (Chrome, Safari, Edge, or Firefox).

🌐 Deploying to Web / Netlify

Since this project is hosted on GitHub and linked to Netlify:

Edit or replace index.html in your GitHub repository.

Click Commit changes.

Netlify will automatically detect the commit and publish your updated app live in 1–2 minutes!

📱 Adding to Tablet Home Screen (iPad / Android)

To open the app full-screen like a native tablet app:

iPad (Safari): Open your app URL, tap the Share icon (square with arrow up), scroll down and tap Add to Home Screen.

Android Tablet (Chrome): Open your app URL, tap the 3 Dots Menu, and tap Add to Home Screen / Install App.
